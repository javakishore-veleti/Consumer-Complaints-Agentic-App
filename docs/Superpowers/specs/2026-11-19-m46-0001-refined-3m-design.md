# M46-0001 / #324 — refined.cfpb_complaints_3m design

## Goal
Working Iceberg Refined (Silver) table for 3m with typed fields, ZIP-3 hygiene, and deterministic `signature_id`.

## Schema (24 columns)
From Raw 3m, plus:
- `zip3` — first 3 digit chars of `zip_code` (else `UNK`)
- `signature_id` — SHA-256 of normalized `product|sub_product|issue|sub_issue|tags|company_response_to_consumer` (lower/trim/coalesce empty)
- `date_sent_to_company` as DATE when parseable
- `_refined_ts` — pipeline timestamp

Retain complaint business + Raw audit cols needed for lineage (`_dataset_slice`, `_source_zip_file`, `_ingest_ts`, `_airflow_run_id`, `_row_hash`).

## Pipeline
1. DDL `demo.refined.cfpb_complaints_3m` (partition `months(date_received)`).
2. PySpark: read `demo.raw.cfpb_complaints_3m` → transform → DELETE+append replace refined.
3. Prove: COUNT(*) = Raw COUNT; signature_id non-null; operator demo DISTINCT signature_id.

## Out of scope
Taxonomy/ML Mode 2, Curated/Gold, registry upsert (M47+).
